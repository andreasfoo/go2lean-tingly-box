Title: Protocol conversion and gateway bugs found by automated testing (57 items, details and repro tests linked)

--- issue body (everything below this line, up to the reviewer notes) ---

We went through tingly-box's protocol converters and the code around them by reading the code and by checking it with [go2lean](https://github.com/andreasfoo/go2lean), a Go-to-Lean model checker, and collected the bugs below in one issue rather than opening dozens. Every item except the two marked † has a small Go test that fails on `b788a3b` (main, 2026-10-20); the two marked † have no standalone repro test yet, and the code they describe is still present on `b788a3b`. Each item links to a page in [andreasfoo/go2lean-tingly-box](https://github.com/andreasfoo/go2lean-tingly-box) with the root cause at file:line, the trigger, observed vs expected behaviour, and the name of its repro test. `scripts/reproduce.sh` copies the repro tests into a tingly-box checkout, runs them with plain `go test` (no go2lean or Lean needed), removes them again, and prints per item whether it still reproduces. We are happy to split any item into its own issue, or to send PRs for the ones you would like fixed.

```sh
git clone https://github.com/andreasfoo/go2lean-tingly-box
cd go2lean-tingly-box
scripts/reproduce.sh ~/src/tingly-box    # an existing checkout, left as it was
scripts/reproduce.sh                     # or: clones tingly-box main into a temp dir
```

Severities are our estimates: **critical** = credentials reach a third party; **high** = a common client/provider path breaks or silently loses what the user asked for; **medium** = wrong results on a less common path, or a loss with a visible symptom; **low** = rare triggers, latent code (no caller in the gateway yet, marked *latent*), test infrastructure. The numbers are the finding numbers used in the linked repository; "Where" points at `b788a3b`.

Related existing issues, not repeated here: #1921, #1923, #1924 (the same bugs as our findings 1-3).
